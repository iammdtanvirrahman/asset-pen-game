# Textures

Put source texture files here, grouped by model if needed. Prefer `.jpg` or `.png` for web delivery. Use clear names such as `table_basecolor.jpg`, `table_normal.png`, and `table_roughness.jpg`.

If textures are packed inside the `.glb`, separate files are not required at runtime. If a model references external textures, keep the relative paths correct and update the model export accordingly.

Note: the older repository folder is misspelled `texures/`; new texture assets should use this correctly spelled `textures/` folder.
