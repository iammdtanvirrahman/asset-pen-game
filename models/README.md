# 3D Models

Place web-ready 3D models in this folder.

- `gallinera_table_4k.glb` — main Pen Fighter tabletop model, exported as a self-contained GLB with embedded materials/textures where possible.

The preview in `../index.html` loads the table from `./models/gallinera_table_4k.glb`. Keep this filename/path in sync with the loader. Optimize the model and texture sizes for mobile performance before committing large assets.
